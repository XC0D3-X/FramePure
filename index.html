02 // POST-PACKAGING PROTOCOL

How to Upload Without Triggering Re-Compression

CRITICAL TRANSPORT RULE

Never trim, edit, or send your packaged file through standard WhatsApp or Telegram chats—messaging apps strip the container and re-compress video into low-bitrate H.264. Transfer between desktop and phone using AirDrop, USB cable, Google Drive, or Telegram "Send as File".

01

Finalize Grading & Audio First

Complete all color grading, captions, audio mixing, and frame rate conforming in DaVinci Resolve, Premiere Pro, After Effects, or CapCut before running the master file through FramePure.

02

Upload via TikTok Web Desktop

Always publish through tiktok.com/upload rather than the standard mobile upload flow.

• Desktop: Chrome, Edge, or Safari
• Mobile: Microsoft Edge / Chrome with "Desktop Site" enabled

03

Bypass TikTok's In-App Editor

Do not apply TikTok filters, stickers, text overlays, or sound replacements during upload. Any modification inside TikTok's editor invalidates direct stream passthrough and forces a server re-encode.
